# 自带功能

这里列出主项目自带的功能，不包含第三方插件。群内发送 `帮助`、`菜单` 或 `help` 可以获取帮助网页地址。

命令中的 `@BOT` 表示在 QQ 中真正 @机器人，不是输入这几个字。`{文本}`、`{图片}`、群号和服务名要换成实际内容，不用输入花括号。“群管理”指群管理员或更高权限的账号；“维护组”指 `SUPERUSERS` 中配置的账号。

默认开启群授权，大部分功能需要群有授权才能使用。没有回复时，也请检查功能开关和是否需要 @机器人。

## 基础功能（basic）

基础娱乐功能合集。

| 功能命令 | 介绍 |
|:---------|:-----|
| 查询授权 | 查询本群授权状态 |
| @BOT戳一戳我 | 让 BOT 戳一戳你 |
| {戳一戳BOT} | 无命令，戳一戳 BOT 触发消息 |
| @BOT翻译 en zh {文本} | 翻译文本 |
| @BOT文字识别 {图片} | 识别图片中文字 |
| @BOT漫画翻译 {图片} | 翻译漫画图片 |
| @BOT选择xxx还是yyy还是zzz | 帮助选择困难症选择 |
| @BOT tql是啥 | 帮你分析抽象拼音缩写是啥意思 |
| 掷骰子 1d6 | 掷骰子，例如掷 1 次 6 面的骰子 |
| 获取b站封面 xxx | xxx 为 b 站视频地址、av 号或直播 id |
| 解析二维码 {图片} | 解析二维码图片的 URL 地址 |
| 参与抽奖 | 参与本群当前已有的抽奖 |
| 查询抽奖 | 查询本群当前的抽奖情况 |
| 创建抽奖 {名字} {数量} | 【群管理】创建抽奖 |
| 结束抽奖 {名字} | 【群管理】结束抽奖 |

> 翻译、文字识别等功能需要访问外部服务，可能因网络或服务变动暂时不可用。

## 核心管理（manager）

服务管理、授权管理、广播和帮助系统。

| 功能命令 | 介绍 |
|:---------|:-----|
| @BOT服务列表 | 【群管理】查询本群所有可见的服务 |
| @BOT启用服务 服务名 | 【群管理】开启本群的指定功能，多个服务名用英文逗号隔开 |
| @BOT禁用服务 服务名 | 【群管理】关闭本群的指定功能，多个服务名用英文逗号隔开 |
| 授权列表 | 【维护组私聊】查询所有授权列表 |
| 好友列表 | 【维护组私聊】查询所有好友列表 |
| 变更授权 123456789+30 | 【维护组私聊】为指定群增加 30 天授权，减天数用 `-30` |
| 检查授权 | 【维护组私聊】手动检查一次授权状态 |
| 广播 g-13131313 广播内容 | 【维护组私聊】广播消息 |
| 退群 123456 管理员操作 | 【维护组私聊】要求 BOT 退群 |

## XQA 你问我答（xqa）

先设置问题和回答，之后发出对应问题，机器人就会回复。例如发送 `我问早上好你答早安`，为自己设置一条问答；群管理员可以用 `有人问早上好你答早安` 设置本群共用的问答。

### 普通问答命令

| 功能命令 | 介绍 |
|:---------|:-----|
| 我问A你答B | 设置个人问题 |
| 有人问C你答D | 【群管理】设置全群问答 |
| 不要回答H | 删除某个回答 H |
| 看看有人问 | 查看全群设置的问题 |
| 看看有人问X | 搜索全群设置的问题 |
| 看看我问 | 查看自己设置的问题 |
| 看看我问Y | 搜索自己设置的问题 |
| 查问答@某人 | 【群管理】查某人的全部问答 |
| 查问答@某人G | 【群管理】搜索某人的问答 |
| @某人不要回答H | 【群管理】删除某人的某个回答 H |

### 维护组管理命令

| 功能命令 | 介绍 |
|:---------|:-----|
| 全群问E你答F | 【维护组】设置所有群都回答的内容 |
| 看看全群问M | 【维护组】搜索所有群的有人问 |
| 全群不要回答N | 【维护组】在每个群的有人问里都删除某个问答 |
| 复制问答from群号1to群号2 | 【维护组】将群号1的有人问复制到群号2 |
| 复制问答from群号1to群号2-self | 【维护组】将群号1的个人问答复制到群号2 |
| 复制问答from群号1to群号2-full | 【维护组】将群号1的全部问答复制到群号2 |
| XQA禁用我问 | 【维护组】禁用该群的个人问答功能 |
| XQA启用我问 | 【维护组】启用该群的个人问答功能 |
| XQA清空本群所有我问 | 【维护组】清空该群所有人设置的我问 |
| XQA清空本群所有有人问 | 【维护组】清空该群的有人问 |
| XQA提取数据 | 【维护组】将数据提取成 xqa_db.json 文件 |
| XQA重建数据 | 【维护组】将 xqa_db.json 再生成 xqa_temp.db 后手动替换 |
