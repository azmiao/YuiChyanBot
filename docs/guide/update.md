# 更新说明

## 更新前先备份

先关闭机器人，再备份下面的内容。复制数据时不要让机器人继续运行。

| 内容 | 位置 |
|:-----|:-----|
| 个人配置 | `yuiChyan/config/` 下的 `.json5` 文件 |
| 问答、群授权、功能开关、图片等数据 | 整个 `yuiChyan/res/` 文件夹 |
| 自行安装的插件 | `yuiChyan/plugins/`，以及插件说明中要求备份的其他文件 |

## 绿色包更新

1. 下载新的绿色包，解压到新文件夹。
2. 将备份的 `.json5` 配置文件和 `res` 文件夹复制到新包的 `yuiChyan/` 对应位置。不要用旧的整个 `config` 文件夹覆盖新版，其中还有程序文件。
3. 有第三方插件时，按插件自己的说明迁移文件和依赖。
4. 双击新目录中的 `启动YuiChyan.bat`，等待环境初始化完成。
5. 确认连接和常用功能正常后，再处理旧目录。不要同时运行新旧两份机器人。

不需要复制旧的 `.venv-portable`，启动脚本会重新准备运行环境，并联网安装所需浏览器。

## 源码更新

关闭机器人，在项目文件夹中运行：

```powershell
git pull
uv sync
uv run playwright install chromium
```

后两条命令也可以用 `更新依赖.bat` 完成。更新后双击 `启动YuiChyan.bat`，或运行：

```powershell
uv run runYuiChyan.py
```

如果 `git pull` 提示本地修改冲突，先保留自己的修改并处理冲突，不要直接强制覆盖。

## 数据会保留吗

主项目的 `.gitignore` 已排除个人 `.json5` 配置、`yuiChyan/res/` 和 `yuiChyan/plugins/`，正常拉取主项目代码不会更新这些文件。不过，删除文件夹或手动覆盖仍可能造成数据丢失，备份不能省。

第三方插件需要单独更新。新版若增加了配置项，请对照 [配置说明](configuration.md) 检查；程序会创建缺失的配置文件，但不会把新字段写入已有文件。
